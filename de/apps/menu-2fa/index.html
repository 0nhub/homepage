Menu 2FA

Deine Codes,
einen Klick entfernt

Menu 2FA ist ein leichtes macOS-Menüleisten-Werkzeug für Zwei-Faktor-Authentifizierung. Lege lokale TOTP-Konten einmal an und kopiere den aktuellen 6-stelligen Code mit einem Klick—ohne eine volle Authenticator-App zu öffnen.

Ein Linksklick auf den Schlüssel öffnet deine Konten und kopiert einen Code in die Zwischenablage. Ein Rechtsklick öffnet Einstellungen, Start bei Anmeldung oder Beenden. Solange das Code-Menü offen ist, wird der Schlüssel zum Countdown-Ring für das 30-Sekunden-Fenster.

Für Tempo und ruhige Sicherheit

Menu 2FA hält Authenticator-Codes in Reichweite und bleibt dir sonst aus dem Weg.

Codes mit einem Klick

Kopiere den aktuellen TOTP-Code für jedes Konto direkt aus der Menüleiste.

Lokal gedacht

Geheimnisse bleiben auf deinem Mac. Codes entstehen auf dem Gerät—ohne Cloud-Sync und ohne Entwickler-Analytics.

Klarer Countdown

Solange das Menü offen ist, zeigt ein Ring, wie viel vom 30-Sekunden-Fenster noch bleibt.

Einfache Einrichtung

Konten mit Titel, optionalem Icon und Base32-Geheimnis anlegen—oder eine otpauth://-URI einfügen.
