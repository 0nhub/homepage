Menu 2FA ist ein fokussiertes macOS-Menüleisten-Werkzeug für Zwei-Faktor-Authentifizierung. Lege deine TOTP-Konten einmal an und kopiere den aktuellen Code mit einem Klick — ohne eine volle Authenticator-App.

Ein Linksklick öffnet deine Konten und kopiert einen Code. Ein Rechtsklick gibt dir Einstellungen oder Beenden. QR-Codes nimmst du über die Webcam oder von einem Screenshot auf.

Enthaltene Funktionen

QR von Kamera oder Bildschirm

Füge Konten hinzu, indem du einen QR-Code mit der Webcam scannst oder ihn von einem Screenshot erfasst.

Drag & Drop

Füge Konten einfach hinzu, indem du ein QR-Bild in den Launcher ziehst.

Freie Positionierung

Verschiebe deine Elemente jederzeit frei und ordne sie nach deinen Vorstellungen an.

Minimalistisch

Die Oberfläche bleibt klar: Einstellungen sind über einen Sekundärklick erreichbar.

Start bei Anmeldung

Menu 2FA startet automatisch, sobald du dich an deinem Mac anmeldest.

Codes erst nach Freigabe

Vor dem Anzeigen der Codes wird eine Authentifizierung verlangt, damit sie geschützt bleiben, bis du sie entsperrst.
