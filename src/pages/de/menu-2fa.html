Menu 2FA ist ein leichtes macOS-Menüleisten-Werkzeug für Zwei-Faktor-Authentifizierung. Lege lokale TOTP-Konten einmal an und kopiere den aktuellen 6-stelligen Code mit einem Klick.

Ein Linksklick öffnet deine Konten und kopiert einen Code in die Zwischenablage. Ein Rechtsklick öffnet Einstellungen, Start bei Anmeldung oder Beenden. Der Schlüssel wird zum Countdown-Ring für das 30-Sekunden-Fenster.

Funktionen

Schneller Zugriff und ruhige Sicherheit in deiner Menüleiste.

Codes mit einem Klick

Kopiere den aktuellen TOTP-Code direkt aus der Menüleiste.

Lokal gedacht

Geheimnisse bleiben auf deinem Mac. Codes entstehen auf dem Gerät.

Klarer Countdown

Ein Ring zeigt, wie viel vom 30-Sekunden-Fenster noch bleibt.

Einfache Einrichtung

Konten mit Base32-Geheimnis anlegen oder eine otpauth://-URI einfügen.

Für sichere Routinen

Für tägliche Anmeldungen

Für einen ruhigen Workflow
