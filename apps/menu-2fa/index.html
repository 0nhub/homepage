Menu 2FA

Download on theMac App Store

Your codes,
one click away

Menu 2FA is a lightweight macOS menu bar utility for two-factor authentication. Store local TOTP accounts once, then copy the current 6-digit code with a single click—without opening a full authenticator app.

A left-click opens your accounts and copies a code to the clipboard. A right-click gives you Settings, Launch at Login, or Quit. While the codes menu is open, the key becomes a countdown ring for the 30-second period.

Functions

Fast access and quiet security, built into your menu bar.

One-click codes

Copy the current TOTP code for any account directly from the menu bar.

Local by design

Secrets stay on your Mac. Codes are generated on-device—without cloud sync.

Clear countdown

A ring shows how much of the 30-second code window remains.

Simple setup

Add accounts with a Base32 secret or paste an otpauth:// URI.

For daily sign-ins

For privacy-minded users

Skip context switching and keep authentication where you already work.
